# Procedural composer -- would this pass as NES game music?

24 pieces, about a minute each. These were written by rules,
not by a model: a chord progression is chosen first and the melody,
bass, accompaniment and drums are all derived from it.

**One question per piece: would this pass as NES game music?**
Write `yes` or `no`.

The Fermata pipeline scores 12/20 -- 60% -- on this exact question,
so that is what this is measured against.

Optional second column if you have the patience: `BEST / GOOD / OK /
BAD`, the stricter standard, where Fermata scores 5/20.
