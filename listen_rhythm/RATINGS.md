# Harmonic rhythm -- 24 matched pairs

Each pair is **one composition, two harmonic pacings.** Same style,
seed, key, tempo, progression and motif. One version changes chords
once per bar; the other changes them at some other rate. Nothing
tells you which is which, and A/B is shuffled per pair.

The original version of these pieces is the batch you called
"fantastic", so matching that is not an improvement -- the new
pacing has to earn a preference.

Three answers per pair:

1. **Would A pass as NES game music?** yes / no
2. **Would B pass?** yes / no
3. **Which is better?** `A`, `B`, or `=`

Comments are the most useful column. Worth noting especially:
pacing, whether the melody sounds cut short, harmonic interest,
and abrupt phrase endings.
