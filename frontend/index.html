Advanced — SNES hardware diagnostics

A memory planning tool, not a sound setting. The SNES mixes echo in a buffer carved out of the same 64 KiB of audio RAM as the instrument samples, so reverb and instruments compete for space. This estimates that trade. It does not add audible reverb to your song — the preview renderer has no echo processor.
